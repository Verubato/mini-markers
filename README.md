# MiniMarkers

Creates spec/class/role/texture markers above party nameplates.

Features:

- Show icons for everyone, or just those in your group.
- High quality class and spec icons.
- Role icons (tank/healer/dps)
- Special icon for bnet friends and guild members.
- Specify a texture to use.
- Class colour your textures.
- Works with nameplate addons such as Plater, Platynator, etc.

This was mostly made for arena to help keep track of your teammates positioning, but can be used for any sort of content where positioning is important.

Requires nameplates to be shown in order for the markers to be shown.

More features will be added over time, so stay tuned!
